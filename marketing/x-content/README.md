# X (Twitter) Content Kit

Weekly batches of founder-voice posts for `@nexomind_ai`. The premise:

- **You post natively** in the X app or Web client. No automation. The X
  algorithm penalizes API-posted content from low-follower accounts by
  ~30–60%, and human posting is the only way the engagement loop works.
- **I draft.** You post. You reply. You iterate. I review weekly and
  adjust the next batch based on what worked.

## Posting principles (for any post in this folder)

1. **The first line is the hook.** X shows ~1.5 lines in the feed before
   "show more". If the first line doesn't create a gap the reader wants
   closed, the post is invisible.
2. **Founder voice, not brand voice.** Write as "I", not "we". NexoMind
   is small enough that founder = brand. Own it.
3. **Links go in replies, not the main post.** X throttles posts that
   contain external links. Post the content first, then reply to your own
   post with the link if needed.
4. **Reply to 5 people in your niche before posting your own content.**
   Therapists, founders, journaling creators, mental-health coaches.
   Specific, useful replies — never "love this!". The algorithm rewards
   incoming engagement on your replies more than standalone posts at low
   follower counts.
5. **Quality > frequency.** One real post a day beats five rushed posts.
6. **Track what worked.** Every Monday, paste your top + bottom post from
   the prior week into chat with rough numbers. I'll adjust the next
   batch.

## Files in this folder

- `week-1.md` — current week's batch + bio + pinned post.
  Future batches will be `week-2.md`, `week-3.md`, etc.

## Account setup (do this once, before week-1)

1. **Bio rewrite** — see `week-1.md`, "Bio" section.
2. **Pinned post** — see `week-1.md`, "Pinned post" section.
3. **Profile photo** — any clean shot of your face. Brands without a
   human face get ~70% less reach at <1k followers.
4. **Header image** — a calm visual that matches the NexoMind aesthetic.
   The cream-on-ink color palette from the site works well. Even a plain
   cream rectangle with no text is fine — better than a stock-photo
   header.
